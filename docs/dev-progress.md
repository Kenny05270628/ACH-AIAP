# 智能面试辅助平台 - 开发进度报告

## 项目概述

- 项目名称：智能面试辅助平台（ACH）
- 开发目标：简历智能分析 + AI 模拟面试
- 技术栈：FastAPI + 原生 HTML/Tailwind CSS + Chart.js + 通义千问 API（SiliconFlow）
- 部署方式：Docker Compose（backend / frontend / PostgreSQL / Redis）
- 统计时间：2026-11-15（上一次更新为 2026-01-14）

## 一、已完成功能

### 1. 后端（FastAPI，`backend/app/main.py`）

- ✅ 应用框架、CORS、Swagger 文档
- ✅ 硅基流动 API 集成（OpenAI SDK 兼容调用）
- ✅ 简历上传接口（PDF / DOCX，格式校验与临时文件存储）
- ✅ PDF 解析（pdfplumber）与 DOCX 解析（python-docx）
- ✅ AI 简历分析：六维度评分（专业技能、项目经验、教育背景、工作经验、沟通能力、学习能力）+ 分析报告
- ✅ **SSE 流式分析接口**：推送 5 个阶段的处理进度，前端显示实时进度条
- ✅ AI 面试问题生成（按岗位、关联简历内容，技术/行为/项目三类）
- ✅ 统一错误处理：401/403/429 等 API 异常返回可读提示
- ✅ JSON 响应预处理：换行符转义，避免解析失败
- ✅ 模型参数可通过环境变量配置（`MODEL_NAME`、`MAX_TOKENS`、`temperature`）

### 2. 前端（`frontend/index.html`，单页应用）

- ✅ 三栏导航：简历上传与分析、AI 模拟面试、历史记录
- ✅ 拖拽/点击上传，文件校验与状态提示
- ✅ 分析进度条（对接 SSE 实时状态）
- ✅ Chart.js 雷达图：低分（<60）隐藏数值标签、14px 指标字体
- ✅ `formatAnalysisReport()`：报告分点换行与排版清理
- ✅ 面试问题列表、折叠展开、答案录入
- ✅ 本地状态持久化（localStorage）与 HTTP 状态处理
- ✅ 移动端自适应侧边栏

### 3. 部署与配置

- ✅ `Dockerfile.backend`（uv + uvicorn，8080）
- ✅ `Dockerfile.frontend`（静态服务，8501）
- ✅ `docker-compose.yml`：backend、frontend、postgres:15、redis:7
- ✅ 密钥与模型配置迁移到 `.env`（`env_file` 注入），提供 `.env.example`
- ✅ `config.py` 支持读取根目录 `.env`，环境变量优先

### 4. 测试与文档

- ✅ 后端测试脚本（`tests/backend/`）

## 五、当前问题与风险

1. **数据易失**：内存存储，服务重启或容器重建后简历/分析结果全部丢失。
2. **API Key 曾泄露**：真实 Key 曾以明文写入 `docker-compose.yml` 并进入 Git 历史；现已改为 `.env` 注入，**仍需到硅基流动控制台轮换该 Key**。
3. **测试覆盖不足**：仅有 3 个脚本式测试，依赖本地 8080 服务与真实 API，未纳入 CI。
4. **会话/历史不闭环**：刷新或更换设备后历史记录丢失。
5. **临时文件无回收**：`temp/` 持续增长。
6. **单机单进程限制**：内存字典与文件本地存储无法水平扩展。
