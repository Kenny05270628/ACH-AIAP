# 智能面试辅助平台 - 开发进度报告

## 项目概述

- 项目名称：智能面试辅助平台（ACH）
- 开发目标：简历智能分析 + AI 模拟面试
- 技术栈：FastAPI + 原生 HTML/Tailwind CSS + Chart.js + 通义千问 API（SiliconFlow）
- 部署方式：Docker Compose（backend / frontend / PostgreSQL / Redis）
- 统计时间：2026-11-15（上一次更新为 2026-01-14）

## 一、已完成功能

### 1. 后端（FastAPI，`backend/app/main.py`）

- ✅ 应用框架、CORS、Swagger 文档
- ✅ 硅基流动 API 集成（OpenAI SDK 兼容调用）
- ✅ 简历上传接口（PDF / DOCX，格式校验与临时文件存储）
- ✅ PDF 解析（pdfplumber）与 DOCX 解析（python-docx）
- ✅ AI 简历分析：六维度评分（专业技能、项目经验、教育背景、工作经验、沟通能力、学习能力）+ 分析报告
- ✅ **SSE 流式分析接口**：推送 5 个阶段的处理进度，前端显示实时进度条
- ✅ AI 面试问题生成（按岗位、关联简历内容，技术/行为/项目三类；兼容数组/对象/单题三种返回结构，失败自动重试）
- ✅ 统一错误处理：401/403/429 等 API 异常返回可读提示
- ✅ JSON 响应修复：逐字符转义字符串内的裸换行/控制字符，非法转义兜底，显著降低解析失败率
- ✅ 模型参数可通过环境变量配置（`MODEL_NAME`、`MAX_TOKENS`、`temperature`）
- ✅ 用户认证：`users` 表 + 注册/登录/我的信息，PBKDF2 密码哈希、HS256 JWT（均在 `backend/app/auth.py`，无额外依赖）
- ✅ 数据归属：简历/面试写入 `user_id`，非本人访问返回 404；游客模式保留，未登录照常可用
- ✅ 我的数据接口：`GET /api/v1/me/resumes`、`GET /api/v1/me/interviews`

### 2. 前端（`frontend/index.html`，单页应用）

- ✅ 三栏主导航（简历上传与分析、AI 模拟面试、历史记录）+ 快捷操作（设置、帮助中心）
- ✅ 设置页：默认目标岗位、回答草稿自动保存、消息通知开关、AI 服务状态检测、清空本地数据
- ✅ 帮助中心：三步使用引导、6 条可折叠 FAQ、快捷入口
- ✅ 用户登录/注册弹窗：邮箱密码注册登录、令牌持久化、侧边栏显示当前账号与退出登录
- ✅ 历史记录面板：登录后读取服务端简历与面试列表，支持展开逐题评分；游客模式展示本次会话并提示登录
- ✅ 拖拽/点击上传，文件校验与状态提示
- ✅ 分析进度条（对接 SSE 实时状态）
- ✅ Chart.js 雷达图：低分（<60）隐藏数值标签、14px 指标字体
- ✅ AI 分析报告结构化渲染：识别标题/段落/列表，统一间距，移除首行缩进与多余空行
- ✅ 简历内容预览前置到“已上传简历”与“分析报告”之间
- ✅ 面试问题列表、折叠展开、答案录入
- ✅ 本地状态持久化（localStorage）与 HTTP 状态处理
- ✅ 移动端自适应侧边栏

## 五、当前问题与风险

1. **API Key 曾泄露（已处置）**：旧 Key 曾以明文写入 `docker-compose.yml` 并进入 Git 历史；现已改为 `.env` 注入，旧 Key 已在硅基流动控制台作废，当前使用新 Key，且已确认 `.env` 未被提交。
2. **测试覆盖不足**：仅有 3 个脚本式测试，依赖本地 8080 服务与真实 API，未纳入 CI。
3. **原始文件不可长期回溯**：`temp/` 已按 TTL 自动清理，超过保留期的简历原文件会被删除；解析文本与分析结果已入库，不受影响。
4. **单机单进程限制**：简历文件仍存本地磁盘，无法水平扩展（数据库已可独立扩展）。
5. **游客数据无隔离**：未登录创建的简历/面试 `user_id` 为空，任何游客都能凭 ID 访问；登录后新建数据才有归属。
6. **SSE 令牌经 URL 传递**：`EventSource` 无法自定义请求头，分析接口通过 `token` 查询参数接收令牌，可能进入访问日志。
